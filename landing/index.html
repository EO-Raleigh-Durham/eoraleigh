The problem every chapter knows

Running an EO chapter is a volunteer job done by busy founders, and every new board picks a new mix of tools. EO Chapter Manager puts the website, events, tickets, member directory, CRM, dues, surveys and board planning into one place.

  • Website builder
  • Event tool
  • Payment links
  • Spreadsheets
  • CRM
  • Survey forms
  • Chat groups
  • Shared drives

  • One platform
1

Too many apps

Events in one tool, payments in another, members in a spreadsheet, partners in a CRM, feedback in forms. Nothing talks to anything, and someone copies data between them by hand.

2

Reset every year

Each new board brings its own favourite tools. Logins, history and how-tos leave with the outgoing chairs, and the chapter manager rebuilds the stack again.

3

No single picture

Nobody can answer simple questions quickly: who is at risk of not renewing, which events members value, how the pipeline is tracking against this year's goal.

Install it for your chapter

It is free and open source. Your chapter owns its copy, its data and its accounts. An AI coding agent does the setup from one README; plan on about an hour.

1

Open an AI agent

Claude Code, Codex, Cursor or similar, in an empty folder on your computer.

2

Paste one sentence

The agent reads the README, asks a few questions about your chapter, and builds the database and website.

3

Log in when asked

You sign in to GitHub, Supabase and Vercel and approve the costs. At the end you get your site's link and an admin login.

Follow the README at https://github.com/dhajdu/eo-chapter-manager and set it up for EO <your chapter>.
You needCostWhat for
GitHubFreeYour chapter's copy of the code
